# Smart Clinic Management System — User Stories

## Admin User Stories

### US-ADMIN-01 — Manage User Access
As an Admin, I want to manage user access to the system so that only authorized users can access the appropriate functionality.

### US-ADMIN-02 — Manage Doctors
As an Admin, I want to manage doctor information so that doctors can be properly maintained in the clinic system.

### US-ADMIN-03 — Manage Patients
As an Admin, I want to manage patient information so that patient records are maintained accurately.

### US-ADMIN-04 — Manage Appointments
As an Admin, I want to view and manage appointments so that the clinic can maintain an organized appointment schedule.

### US-ADMIN-05 — Manage System Functionality
As an Admin, I want to manage system functionality so that the clinic system operates according to administrative requirements.


## Patient User Stories

### US-PATIENT-01 — Book an Appointment
As a Patient, I want to book an appointment with a doctor so that I can receive medical consultation.

### US-PATIENT-02 — View Appointments
As a Patient, I want to view my appointments so that I can keep track of my scheduled consultations.

### US-PATIENT-03 — Manage Appointments
As a Patient, I want to manage my appointments so that I can keep my appointment schedule up to date.

### US-PATIENT-04 — View Patient Dashboard
As a Patient, I want to access my patient dashboard so that I can view information relevant to my clinic activities.

### US-PATIENT-05 — View Patient Records
As a Patient, I want to view my patient records so that I can access my medical information.


## Doctor User Stories

### US-DOCTOR-01 — Manage Availability
As a Doctor, I want to manage my availability so that patients can book appointments during my available time slots.

### US-DOCTOR-02 — View Appointments
As a Doctor, I want to view my appointments so that I know which patients I need to attend to.

### US-DOCTOR-03 — Manage Patient Appointments
As a Doctor, I want to manage my patient appointments so that I can effectively organize my consultation schedule.

### US-DOCTOR-04 — View Patient Information
As a Doctor, I want to view patient information so that I can understand the patient's details before providing consultation.

### US-DOCTOR-05 — Manage Prescriptions
As a Doctor, I want to manage patient prescriptions so that prescription information can be maintained as part of the patient's medical information.
